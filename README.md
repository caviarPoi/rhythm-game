# PULSE / BUBBLE

静态网页双指泡泡音游和制谱器。不需要 npm、服务器后端或第三方库。

## 部署
将本目录内全部文件上传到 GitHub Pages 的发布根目录（index.html 所在目录）。不要只上传 HTML。访问原网站地址进入游戏；右上角 STUDIO 进入编辑器。编辑器试玩通过同源窗口消息传送谱面与音乐，因此建议使用 GitHub Pages（本地 file:// 可能无法试玩跨窗口传输）。

## 制谱
导入本地音乐，工具/属性中设置 BPM、首拍和节拍吸附。画布逻辑尺寸 960×540，默认空间网格为 60 像素，边缘留 60 像素。关闭网格即自由放置；录制期间采集原始路径，停止后若网格开启，则起点、中间节点、终点吸附到网格。时间吸附独立设置。录制支持单点、长按、滑条、多指操作。导出 JSON 后，音乐原文件需另行保留。

## 文件
- index.html：游戏入口、选曲、游玩、结算
- editor.html：编辑器入口
- style.css：共享样式、响应式布局
- common.js：共享路径计算、音频读取、触屏保护
- game.js：游戏逻辑
- editor.js：编辑和录制逻辑

谱面标识 pulse-bubble-1；本版不保证旧版谱面兼容。

## 横屏版
手机竖屏时显示旋转提示。Safari 普通网页不能可靠强制旋转；游玩中转回竖屏会退出本局，制谱时会停止录制或暂停播放。选曲右侧独立滚动，左侧展示封面、信息、难度和开始按钮。单点白色、长按金色、滑条青蓝色；判定文字持续 320ms，击打扩散圈持续 160ms。保留原版谱面格式与制谱流程。
