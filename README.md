# PULSE / BUBBLE

静态网页双指泡泡音游和制谱器。不需要 npm、服务器后端或第三方库。

## 部署
将本目录内全部文件上传到 GitHub Pages 的发布根目录（index.html 所在目录）。不要只上传 HTML。访问原网站地址进入游戏；右上角 STUDIO 进入编辑器。编辑器试玩通过同源窗口消息传送谱面与音乐，因此建议使用 GitHub Pages（本地 file:// 可能无法试玩跨窗口传输）。

## 制谱
导入本地音乐，工具/属性中设置 BPM、首拍和节拍吸附。画布逻辑尺寸 960×540，默认空间网格为 60 像素，边缘留 60 像素。关闭网格即自由放置；录制期间采集原始路径，停止后若网格开启，则起点、中间节点、终点吸附到网格。时间吸附独立设置。录制支持单点、长按、滑条、多指操作。导出 JSON 后，音乐原文件需另行保留。

## 文件
- index.html：游戏入口、选曲、游玩、结算
- editor.html：编辑器入口
- style.css：共享样式、响应式布局
- common.js：共享路径计算、音频读取、触屏保护
- game.js：游戏逻辑
- editor.js：编辑和录制逻辑

- editor-tracks.js：轨道编辑、待摆放、校准及打击音预览

## 横屏版
手机竖屏时显示旋转提示。Safari 普通网页不能可靠强制旋转；游玩中转回竖屏会退出本局，制谱时会停止录制或暂停播放。选曲右侧独立滚动，左侧展示封面、信息、难度和开始按钮。单点白色、长按金色、滑条青蓝色；判定文字持续 320ms，击打扩散圈持续 160ms。保留原版视觉和空间制谱流程。


## Track Edition
- 空间 / 轨道切换共享谱面、选择和撤销。轨道纵向波形与节拍线同步；选择工具拖动音符或长条头尾，浏览工具滑动时间，框选后可批量微调。
- 轨道录制使用 D F J K 或屏幕底部按键，生成待摆放单点/长按。空间录制保留位置。默认智能校准弹窗预览后应用，原始时间可保留；BPM 和首拍仍需人工确认。
- 待摆放按钮逐个定位，点击画布摆放；滑条拖动起终点。保存工程保留未摆放状态，导出游戏谱面和试玩要求全部摆放。
- 新版游戏谱面格式 pulse-bubble-2，工程格式 pulse-studio-2，不兼容旧版。音乐文件仍需单独导入。

## iOS 保存与试玩修复
保存工程及导出优先调用系统文件分享菜单，选择“存储到文件”；若浏览器不支持文件分享则使用下载。工程不包含音乐。试玩先在 IndexedDB 保存谱面和音频文件，再点击“打开试玩”，待提示资源就绪后点击 PLAY。此流程要求同一站点允许本地存储，不使用跨窗口消息。试玩暂存仅保留最近一次资源。
