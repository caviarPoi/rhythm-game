# PULSE / BUBBLE

静态网页双指泡泡音游和制谱器。我的VibeCoding许愿产物。

## 制谱
导入本地音乐，工具/属性中设置 BPM、首拍和节拍吸附。画布逻辑尺寸 960×540，默认空间网格为 60 像素，边缘留 60 像素。
关闭网格即自由放置；录制期间采集原始路径，停止后若网格开启，则起点、中间节点、终点吸附到网格。
时间吸附独立设置。录制支持单点、长按、滑条、多指操作。导出 JSON 后，音乐原文件需另行保留。

## 文件
- index.html：游戏入口、选曲、游玩、结算
- editor.html：编辑器入口
- style.css：共享样式、响应式布局
- common.js：共享路径计算、音频读取、触屏保护
- game.js：游戏逻辑
- editor.js：编辑和录制逻辑
